Mini-guides pratiques

Apprenez les gestes essentiels pour naviguer sur internet, étape par étape.

📋 Sélectionner et copier du texte

Sur n'importe quelle page, vous pouvez copier un texte pour le coller ailleurs.

  1. 1
    Cliquez au début du texte que vous voulez copier et gardez le bouton enfoncé.
    Voici un texte exemple sur la page.
  2. 2
    Faites glisser la souris jusqu'à la fin du texte voulu, puis relâchez. Le texte apparaît surligné en bleu.
  3. 3
    Appuyez sur Ctrl + C pour copier. Ou : clic droit sur la sélection → "Copier".
    ↪ Ouvrir dans un nouvel onglet
    📋 Copier
    🔎 Rechercher "texte exemple"
  4. 4
    Allez à l'endroit où coller (e-mail, formulaire…) et appuyez sur Ctrl + V.
💡 Double-clic = sélectionne un mot entier. Triple-clic = sélectionne tout un paragraphe.

🖱️ Le clic droit : à quoi ça sert ?

Le bouton droit de la souris ouvre un menu avec des options selon l'endroit où vous cliquez.

  1. 1
    Clic droit sur du texte sélectionné
    📋 Copier
    ✂️ Couper
    🔎 Rechercher...
    🌍 Traduire...
  2. 2
    Clic droit sur une image
    💾 Enregistrer l'image sous...
    📋 Copier l'image
    🔎 Rechercher cette image
  3. 3
    Clic droit sur un lien
    ↗ Ouvrir dans un nouvel onglet
    📋 Copier l'adresse du lien
    🛡️ FaciliWeb : Analyser ce lien
  4. 4
    Clic droit sur la page (fond vide)
    🌍 Traduire en français
    🖨️ Imprimer...
    💾 Enregistrer sous...
💡 Pour fermer le menu sans rien faire, appuyez sur Échap ou cliquez ailleurs.

🌍 Traduire une page web entière

Vous tombez sur un site en anglais ou dans une autre langue ? Le navigateur peut tout traduire en un clic.

  1. 1
    Méthode 1 — Barre d'adresse (Chrome) : Quand Chrome détecte une langue étrangère, un petit bouton "Traduire" apparaît à droite de la barre d'adresse. Cliquez dessus.
    🔒 en.wikipedia.org/wiki/… 🌍 Traduire
  2. 2
    Méthode 2 — Clic droit : Faites un clic droit sur le fond de la page → "Traduire en français".
  3. 3
    Méthode 3 — Google Traduction : Copiez l'adresse de la page (dans la barre d'adresse) et collez-la sur translate.google.fr.
💡 Pour traduire juste un mot ou une phrase, sélectionnez-le → clic droit → "Rechercher … sur Google" ou copiez sur DeepL.

🔎 Trouver un mot sur une page

Sur une longue page, plutôt que de lire tout, demandez au navigateur de trouver le mot pour vous.

  1. 1
    Appuyez sur Ctrl + F. Une petite barre de recherche apparaît en haut à droite de la page.
    remboursement 3 / 7 ↑ ↓
  2. 2
    Tapez le mot à chercher. Les occurrences sont surlignées en jaune sur la page.
  3. 3
    Utilisez les flèches ↑ ↓ pour passer d'une occurrence à la suivante.
  4. 4
    Appuyez sur Échap pour fermer la barre de recherche.

🗂️ Ouvrir un lien sans quitter la page

Pour consulter un lien tout en gardant la page actuelle ouverte.

  1. 1
    Méthode 1 : Clic droit sur le lien → "Ouvrir dans un nouvel onglet".
  2. 2
    Méthode 2 : Maintenez Ctrl enfoncé pendant que vous cliquez sur le lien.
  3. 3
    Le lien s'ouvre dans un nouvel onglet. Basculez entre les onglets en cliquant sur leurs titres en haut du navigateur.
💡 Pour revenir à l'onglet précédent : appuyez sur Ctrl + Maj + Tab (onglet précédent) ou Ctrl + Tab (onglet suivant).

♻️ Récupérer un onglet fermé par erreur

Vous avez fermé un onglet par accident ? Il est récupérable !

  1. 1
    Appuyez sur Ctrl + Maj + T immédiatement après la fermeture.
  2. 2
    L'onglet se rouvre à l'endroit exact où vous étiez.
  3. 3
    Répétez la combinaison pour récupérer les onglets fermés encore plus tôt.
💡 Fonctionne aussi pour rouvrir plusieurs onglets fermés, dans l'ordre inverse de fermeture.

🔍 Agrandir le texte d'une page

Si le texte est trop petit pour être lu confortablement, zoomez sur la page.

  1. 1
    Appuyez sur Ctrl + + pour agrandir. Répétez jusqu'à la taille confortable.
  2. 2
    Appuyez sur Ctrl + − pour réduire.
  3. 3
    Appuyez sur Ctrl + 0 (zéro) pour revenir à la taille normale (100 %).
💡 Sur une souris avec molette : maintenez Ctrl et faites rouler la molette vers le haut pour zoomer, vers le bas pour dézoomer.

🖨️ Imprimer une page ou la sauvegarder en PDF

Imprimez une page ou enregistrez-la en PDF sans imprimante.

  1. 1
    Appuyez sur Ctrl + P pour ouvrir la fenêtre d'impression.
  2. 2
    Pour imprimer : sélectionnez votre imprimante dans la liste et cliquez "Imprimer".
  3. 3
    Pour sauvegarder en PDF : dans la liste des imprimantes, choisissez "Enregistrer au format PDF".
  4. 4
    Choisissez où enregistrer le fichier et cliquez "Enregistrer".
💡 Avant d'imprimer, regardez l'aperçu pour éviter de gâcher du papier. Cochez "Arrière-plan" si les images n'apparaissent pas.

🖼️ Enregistrer une image

Téléchargez une image trouvée sur internet sur votre ordinateur.

  1. 1
    Clic droit sur l'image.
  2. 2
    Choisissez "Enregistrer l'image sous…".
  3. 3
    Une fenêtre s'ouvre : choisissez le dossier de destination (ex : Bureau, Images).
  4. 4
    Cliquez "Enregistrer". L'image est maintenant sur votre ordinateur.
⚠️ Vérifiez les droits d'auteur avant de réutiliser une image trouvée sur internet.

📸 Faire une capture d'écran

Photographiez ce qui est affiché sur votre écran pour le partager ou le garder.

  1. 1
    Tout l'écran : appuyez sur la touche Impr. écran (parfois notée PrtScn). L'image est copiée dans le presse-papiers. Collez-la dans un e-mail ou un document avec Ctrl+V.
  2. 2
    Fenêtre active uniquement : Alt + Impr. écran — capture seulement la fenêtre ouverte.
  3. 3
    Sélection libre (Windows 10/11) : Windows + Maj + S — un outil s'ouvre pour sélectionner la zone à capturer.
  4. 4
    Les captures sont aussi sauvegardées automatiquement dans le dossier Images → Captures d'écran.

🧹 Vider le cache (si le site est lent ou bloqué)

Quand un site ne se charge pas correctement, vider le cache règle souvent le problème.

  1. 1
    Appuyez sur Ctrl + Maj + Suppr pour ouvrir le menu de nettoyage.
  2. 2
    Cochez au minimum : "Cookies et autres données de site" et "Images et fichiers en cache".
  3. 3
    Choisissez la période : "Toute la période" pour un nettoyage complet.
  4. 4
    Cliquez "Effacer les données", puis rechargez la page avec F5.
⚠️ Vous serez déconnecté des sites où vous étiez connecté. Ayez vos mots de passe à portée.

⭐ Ajouter un site en favoris (marque-page)

Retrouvez facilement un site sans avoir à retaper son adresse.

  1. 1
    Allez sur la page que vous voulez mémoriser.
  2. 2
    Appuyez sur Ctrl + D, ou cliquez sur l'étoile ⭐ à droite de la barre d'adresse.
  3. 3
    Donnez un nom au favori si besoin et choisissez le dossier. Cliquez "Terminé".
  4. 4
    Pour retrouver vos favoris : appuyez sur Ctrl + Maj + O ou cliquez sur ⭐ dans la barre latérale.
